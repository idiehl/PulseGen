# PulseGen 0.1.0-alpha.20

PulseGen is an experimental Windows sound laboratory. Make or import a sound,
draw its movement through a three-dimensional scene, choose where to listen,
and render what each listener or microphone pair receives as a stereo take.

## Run the portable build

Download `PulseGen-0.1.0-alpha.20-win-x64.zip` from
[this release](https://github.com/idiehl/PulseGen/releases/tag/v0.1.0-alpha.20),
extract the entire folder, and open `PulseGen.exe`. Keep the bundled files and
folders together. Read `START_HERE.txt` or use the opening guide to explore the
Doppler flyby and surface echo examples. Windows 11 x64 and headphones are
recommended. The package includes the .NET and Python runtimes. An account is
not required for local sound creation, analysis, or export.

This build is unsigned prerelease software. There is no installer or automatic
updater. Keep a separate copy of important projects and recordings while testing.

## Available now

- Create basic waveforms, additive tones, several kinds of noise, impulses, and
  procedural wind; import WAV, AIFF, FLAC, MP3, Ogg Vorbis, and Opus recordings.
- Place sounds, listeners, microphones, paths, rooms, surfaces, imported static
  meshes, and atmospheric fields in one scene. Preview movement, propagation
  delay, Doppler pitch changes, distance loss, obstruction, and simulated echoes.
- Choose an analytic binaural listener or independently positioned stereo
  microphone capsules. Each receiver rig produces its own stereo take.
- Work with the original stereo recording deliberately: separate moving left
  and right sources, a stereo background, or an explicit mono mix.
- Render takes, arrange and trim them, edit left and right independently, and
  export WAV/BWF/RF64, AIFF, FLAC, MP3, Ogg Vorbis, or Opus with explicit output
  settings and no automatic normalization.
- Analyze audio into editable tonal tracks plus transient and noise layers.
  Preserve the original and an exact reconstruction residual in the project.
- Save content-addressed projects and portable PulsePack archives locally.
  Atlas sign-in and sync are explicit, optional actions; the availability of
  hosted identity/library services is separate from this desktop release.

## Alpha.20 interface changes

Playback has a persistent strip with Start/rewind, one-second steps, Play/Pause,
Stop, exact-time entry, and a draggable ruler. Space plays or pauses outside text
fields, Home rewinds, and Play at the end starts again at zero.

The 3D World has separate Select, Move, Orbit, and Pan tools. Focus selection
sets a fixed camera pivot. Top, Front, and Side views provide accurate flat
views, and moving points supports exact XYZ coordinates, axis or plane
constraints, 0.1 metre snapping, a ground pin, and live coordinate feedback.
Editing a position never seeks playback. Escape cancels an unfinished drag.

## Current limits

- Windows 11 x64 only. No live microphone recording, MIDI, plugin hosting, ASIO,
  or real-time collaboration in this alpha.
- The active binaural model uses analytic ear timing and head shadowing.
  Imported measured SOFA profiles remain render-gated until their adapter is
  ready. Steam Audio is not presented as an active dependency.
- Demucs and AudioSep adapters remain unavailable and model weights are not
  included. Tonal decomposition does not identify an unknowable set of original
  sound sources.
- Echoes and wind use bounded geometric, modal, and acoustic-field approximations,
  rather than full wave simulation or computational fluid dynamics. Imported
  meshes are static. Sampled spatial sources currently use a 1 kHz reference
  for scalar air and material gains, limiting broadband surface coloration.
- Active unique decoded recordings share a 64 MiB budget. Stereo backgrounds
  bypass spatial source/receiver acoustics. The importer rejects unsupported,
  incomplete, or non-finite streams.

## Provenance and verification

This public distribution retains the alpha.20 sound and spatial-editing features
from commit `d11a46fceb4602ddcc00f60bdbbdc0d3820daca5`. Its managed application was
rebuilt with an explicit codec replacement option, accurate replacement-runtime
provenance, and compatibility with installed .NET 10 SDK feature bands. The
package manifest records the exact release source commit. The public package
also contains the resolved third-party license and copyright notices.

The adjacent `PulseGen-0.1.0-alpha.20-third-party-sources.zip` contains codec
sources, reference build recipes, and an identity index for the bundled runtime.
It is provided for source access and modification; it is not needed to run the
app. To deliberately use a compatible replacement libsndfile DLL, set
`PULSEGEN_SNDFILE_PATH` to its full path before opening PulseGen. Both import and
export record that runtime's real version and hash. The bundled default is
still checked against its pinned hash.

Download the adjacent `.zip.sha256` file and compare it with:

```powershell
Get-FileHash .\PulseGen-0.1.0-alpha.20-win-x64.zip -Algorithm SHA256
```

From the source checkout, run:

```powershell
./scripts/verify-package.ps1 -PackagePath ./PulseGen-0.1.0-alpha.20-win-x64.zip
```

The verifier checks the manifest and every file hash, starts the packaged native
engine, checks the codecs and local analysis host, opens both starter projects,
imports a generated test recording, renders isolated stereo takes, and rechecks
the payload for changes. This verifies packaging and headless workflows; it
does not substitute for listening tests or guarantee performance on every PC.
